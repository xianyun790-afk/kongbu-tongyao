# 恐怖童谣 · 游戏 Demo：我的制作思路

我想做的是一段能让人“亲自调查”的悬疑体验。打开游戏后，玩家先看到一个有生活痕迹的房间：窗外在下雨，桌上有烛光，旧广播和磁带留在原来的位置。疑问从这些东西里出现，玩家再决定先查什么。

这个想法受芒果 TV《明星大侦探·恐怖童谣》的悬疑氛围启发。我喜欢旧空间、童年记忆和熟悉物件之间产生的不安感，希望把这种感受转成可以探索的游戏场景。本项目是个人非官方概念 Demo，展示不代表获得节目官方改编授权。

## 从读流程，变成找线索

早期版本里，玩家需要依次点击多个步骤，人物陈述和线索都比较依赖文字。材料虽然能读完，但玩家主动发现问题的空间太少。

所以我希望把调查权交给玩家：先选一件让自己在意的旧物，近看它，再找能与它对照的材料。重要信息仍然要清楚呈现，但界面不应该一开始就把所有内容铺满，也不应该替玩家提前解释每一个结论。

目前的小谜围绕一段广播中的缺口展开。玩家收集三组公开材料，通过声音文本的差异与生活旧物相互核对，最后提交自己的判断。提交后需要有回应，让玩家知道哪些依据成立、还缺什么，而不只是保存一句答案。

## 先做一个小闭环

我没有先把整套多人剧本铺开，而是把第一段体验缩成约 5—10 分钟。它需要有明确的来由、可执行的调查目标、能互相印证的材料，以及一个清楚的阶段结束。

这段 Demo 用来验证几件具体的事：玩家进门后是否知道要做什么；是否愿意点击场景里的东西；能否理解物件之间的联系；提出判断后是否得到足够的反馈。把这些做好，再增加角色和剧情，才有稳定的基础。

因此，当前餐厅可以完成一个小谜；值班室用于展示后续空间和调查氛围，尚未接入完整第二轮。场景开放不等于整段案情已经制作完成。

## 美术要有真实的触感

画面方向是带有中世纪欧洲旧宅气质的虚构空间：深色旧木、厚重窗帘、磨损地板、暗色地毯、银器、冷雨和暖烛光。这里追求的是空间的年代感与悬疑感，没有血腥或突然惊吓的设计。

我尤其在意桌面和家具的细节。瓷杯里的残液、纸张边缘、木材磨损、人物衣褶和窗外的远景，都应该让人相信有人在这里生活过。制作时结合自行建模与现成的真实素材，逐步调整材质、比例和摆放，减少泛化的“AI 画面感”。外部素材的作者与许可单独记录，不把整间房子笼统说成全部原创。

房间本身由真实三维网格组成。玩家改变视角时，物件的位置、透视和遮挡也会改变；这让我能用近看、转动物件和切换房间来组织调查。

## 界面少一点，交互顺一点

主画面尽量留给场景。可调查的位置用柔光点提示，正文通过居中的纸卡展示；阅读完可以收起卡片，留在物件旁继续观察。字体、对比度和正文可见性需要优先保证，不能为了旧纸质感让人读不清。

进入时用一段简短的开门与推进镜头建立空间感，随后交还操作。自由环顾要避开墙面和家具，近看后再次拖动或缩放，也应能继续发现其他调查点。录音、识别和主持回复需要清楚反馈；结束后的字幕要退场，避免一直挡住现场和任务。

这些细节的目标很朴素：玩家把注意力放在房间和疑问上，不必反复处理界面。

## AI 做主持人，真人做角色

后续我希望尝试“6 名真人＋AI 公共 DM”的玩法。每个真人拿到自己的角色本，自己决定如何陈述、隐瞒、分享和讨论。AI 负责开场、节奏、公开材料核对和玩家主动请求的提示，不替真人角色表态，也不把未公开的私人信息混进公共回答。

当前 GitHub Pages 版先让别人方便打开、体验和反馈。它只提供预设文字主持，没有实时 AI 语音、麦克风识别、多人房间或私人剧本权限管理。实时服务需要另外部署后端后接入，不能由静态网页独立完成。

接下来扩展的重点，是让更多场景中的物件真正参与调查，让玩家的发现能够推动下一次提问与讨论。先确认这个小谜是否好玩，再逐步把它长成完整的多人体验。
